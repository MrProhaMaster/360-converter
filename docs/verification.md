# Проверка 25 ноября 2026

## Локальная среда

Windows 10 x64 (10.0.19045), Python 3.14.0, Pillow 13.0.0, pytest 9.2.0, PyInstaller 6.22.3. FFmpeg 9.0.2 essentials (Gyan), получен из `imageio-ffmpeg` 0.8.1 только для локальной проверки. Точные версии среды — `requirements-dev.lock.txt`.

## Автоматические проверки

`python -m pytest -q`: **26 passed**, включая:

- диапазоны углов, NaN/Infinity, размеры, лимит квадратных граней;
- чтение и запись пресетов, отказ для неверной схемы;
- отклонение повреждённого JPEG, пропорций не 2:1, EXIF Orientation;
- сохранность исходника, отказ перезаписи, конкурентное появление выходного файла;
- очистка временного файла при ошибке кодировщика;
- отмена запущенного процесса и тайм-аут;
- фактический экспорт 1/4/6 через FFmpeg, размеры, ICC и отсутствие EXIF;
- геометрия направлений шести граней на синтетической панораме с известными цветами;
- поворот и наклон, продолжение пакета после ошибки, отмена после первого кадра;
- одинаковые имена источников в разных папках, индивидуальные настройки;
- CLI и его коды завершения;
- создание Tk-окна, фоновый предпросмотр, пакетный экспорт из GUI и закрытие.

В первоначальном изолированном запуске Tk не смог прочитать системный Tcl и GUI-тест был пропущен. Повтор в обычном профиле Windows с отдельной временной папкой завершился **без пропусков**. Это ограничение среды проверки, а не требование запускать приложение от администратора.

## Реальные фотографии

Пять исходных панорам из указанного чата локально преобразованы в 20 JPEG (по четыре на файл), 1024×768. ICC каждой фотографии сравнен побайтово с источником; контрольные суммы всех источников до и после совпали. EXIF в результатах отсутствует. Эти фотографии и результаты тестирования не входят в Git.

## Windows-сборка

Переносимая сборка PyInstaller `onedir` создана непосредственно на Windows x64. Python и Tk включены; FFmpeg поставляется отдельно. Фактический запуск окна EXE проверен. Визуальная проверка выявила обрезание нижней строки состояния; раскладка исправлена, тесты выполнены повторно.

## Границы проверки

Не проверены чистая виртуальная машина без установленного Python, Windows 11/ARM, экранный диктор, все варианты DPI/масштабирования, сетевые/FAT-диски, реальные сбои питания и панорамы на предельных размерах. Tk имеет ограниченную поддержку Windows UI Automation; управление с клавиатуры доступно, но полная совместимость с экранным диктором не заявляется. EXE не подписан сертификатом и не снабжён установщиком.

Исходный ZIP прототипа недоступен, поэтому нет проверки его исходного кода, импорта старой схемы `user_photos.json` и совпадения пикселей с прежними 20 результатами. Новые результаты используют настройки по умолчанию, а не неизвестные персональные углы старого пресета.

GitHub Actions настроен для Windows-тестов и сборки. Фактический результат облачного запуска следует проверять на вкладке Actions; наличие workflow само по себе не подтверждает успешность запуска.
