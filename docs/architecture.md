# Устройство приложения

`converter_360/core.py` — проверка входных JPEG, валидация параметров, проекция FFmpeg, управление процессом, ICC, безопасная запись и пакетный отчёт. Модуль не импортирует GUI и не обращается к сети.

`converter_360/gui.py` — главное окно Tk с двумя последовательными рабочими очередями: предпросмотр и экспорт. Изменение параметров отменяет устаревший предпросмотр. Номер поколения не позволяет запоздавшему кадру заменить актуальный. Все операции Tk выполняются в главном потоке. Экспорт фиксирует список файлов и настройки при запуске, поэтому дальнейшее редактирование не меняет уже начатую задачу.

`converter_360/cli.py` использует тот же механизм. Формат `schema_version: 1` задаёт переносимые числовые настройки, без исходных путей. Индивидуальные назначения GUI живут только в сеансе. Отчёт экспорта сохраняет фактические параметры каждого кадра.

Путь изображения передаётся FFmpeg отдельным аргументом после `-i`, не вставляется в текст фильтра. Все числа фильтра проходят конечность и диапазоны. Новый кадр записывается рядом с назначением, синхронизируется на диск и публикуется без перезаписи. Windows использует `os.rename`, POSIX — hard link. Источники открываются только для чтения.

Обычный вид — `v360 e→flat` с заданным порядком `ypr`. Пакет 4/6 сначала корректирует всю сферу `e→e`, затем извлекает отдельные плоскости. В шести видах угол и пропорции фиксированы, чтобы покрытие сферы не зависело от пользовательского FOV.

Проект намеренно не угадывает горизонт и сюжет. Разрешение входа и выходного кадра ограничено; один FFmpeg завершается по отмене или 180-секундному тайм-ауту. Ошибки конкретного файла попадают в отчёт, затем обрабатывается следующий файл.
